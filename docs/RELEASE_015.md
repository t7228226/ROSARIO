# 015 更新紀錄

版本：`2026-10-29-015`。本次直接更新正式版，不另建測試站。

## 修改與原因

- `src/App.tsx`：試排已安排名單納入固定站長，姓名與人數一致；站長為綠色，訓練仍保留黃色及文字。
- `src/domain/workforce/configuration.ts`、`src/features/gap-analysis/CoverageConfigurationOverview.tsx`：配置摘要直接顯示姓名，展開後可指定合格人選、解除固定、復原及還原系統配置。變更取代同一人的前次指定，使用既有最大匹配重算其他站點；不把多人共用資格視為多份人力。
- 配置沿用缺勤、離職、幹部支援與補訓假設，補訓建議及壓力測試採相同固定條件。比較原始與固定後最佳缺口，顯示調動來源與去向。候補包含合格幹部，但只有明確指定才加入作業配置；實際訓練中人員不自動當作合格。
- 自訂配置只存在目前記憶體，切換班別、日別、資料、缺勤或其他情境條件即失效，不修改正式資格或雲端班表。復原保留最多 20 步。
- `src/scenario-analysis.css`：桌機及手機統一逐站摘要／展開，維持置中與既有主題；候補顯示目前站點，避免姓名黏連。
- `src/components/ui/AppDialog.tsx`：焦點圈選排除收合內容，保留可見 summary，避免新候補區影響鍵盤操作。
- `gas-login-fallback-2026-07-01.js`、`src/lib/gasClient.ts`：登入及工作階段恢復可在同一次驗證請求回傳核心資料；客戶端只採用相符 token、revision、版本及資料形狀的結果。啟動略過操作紀錄查詢／清理，開啟操作中心時再查詢。保留資料前後 fingerprint、帳號授權與寫入版本限制，未新增跨請求的人事資料快取。
- 權限設定仍在核心資料完成後載入。獨立審閱發現 React 18 批次更新可能漏掉權限載入，已補上人員數量相依條件。
