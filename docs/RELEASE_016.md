## 完成項目

- 配置與視窗可見性分離：關閉／收起只隱藏畫面；暫停自訂配置保留規則；恢復系統預設清空本次配置但保留缺勤、離職情境與已儲存的雲端預設。復原最多 20 步。
- 配置依帳號、班別、日別隔離；在本次登入中切換功能或日別不再清除調整。尚未存成預設的調整仍只在記憶體內，重新整理後不保證保留。
- 個人雲端預設可命名、更新、套用及指定該班別／日別的預設配置。只在明確儲存時建立 `13_配置預設`；不寫入人員、出勤或資格主檔。每個帳號與班別／日別最多 20 份，可更新既有項目。
- 固定單站、限定多站、優先多站共用資格／出勤／一人一站核心；固定與限定可能增加缺口，系統如實顯示。優先站點為軟性排序，不犧牲全站最大覆蓋與支援優先，也不宣稱所有偏好全域最優。
- 覆蓋、缺勤／離職、補訓及幹部支援沿用相同限制；實際試排另外保留管理勤務與臨時勤務。補訓完成及領班以上緊急支援假設不會自動匯入實際試排。
- 試排規則變動不立即覆蓋手動站位；重新自動安排才套用。預覽前再次阻擋不符合固定／限定規則的站位。站長仍正常計入作業人力。
- 失效／缺勤規則提供警告；限定站點全部失效時不會放寬成任意站點。同站超額指定不會抵銷其他站缺口。
- 預設讀寫使用既有授權、版本、revision、操作憑證與回滾保護。管理員也不能讀取其他人的個人預設。結果不明時凍結原儲存內容，重試核對同一操作；新預設 ID 由伺服器產生。
