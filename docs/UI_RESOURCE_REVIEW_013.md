# 013 介面資源與實際檢視

既有 React 與 AppDialog 為本次主體，保留五主題、姓名置中及既有資訊密度，不重新設計品牌或加入外部 UI 套件。
延續 `UI_RESOURCE_REVIEW_012.md` 的資源盤點；本階段實際查閱本機 UI 資源 catalog 的 ui-ux-pro-max 項目與 ux-guidelines loading/feedback 指引。
採用可見送出狀態、防重送與不搶焦點的進度原則，未複製外部介面程式碼、素材或字型。

## 可見問題與修正

1. 原生 confirm/prompt 與網站視覺割裂，且內嵌瀏覽器故障測試曾卡住。改用既有 AppDialog，Enter/IME、取消、巢狀 Escape 實際測試。
2. 視窗標題受右側關閉鈕影響偏移。改成等寬 44px 側欄，維持真正中央標題與觸控範圍。
3. 操作結果原本只有短暫提示，超時不確定無法追查。新增操作狀態入口、metadata 回條、狀態篩選、人工核對及分頁。

## 畫面審查

- 階層：標題、篩選、每筆動作及狀態、底部重新查詢／載入資料具不同視覺層級。
- 密度：每筆只顯示動作、時間、版本與狀態；冗長操作編號預設折疊。
- 字體／對齊：依使用者偏好置中，標題等寬兩側留位，文字使用現有系統字型。
- 間距：紀錄以分隔線區分，不再疊加卡片；對話框操作區固定可到達。
- 色彩：沿用成功、風險、錯誤語意，另有文字狀態，不僅依賴顏色。
- 控制／狀態：實測已完成、版本衝突、待確認、已人工核對；人工核對不偽裝原操作成功。
- 識別：保留 TSEC 人力站點與目前圖示，不新增裝飾性圖片。

本機瀏覽器已檢視 desktop、390px 與 320px 窄版畫面；量測無頁級水平溢位，篩選與底部按鈕可操作。
實際截圖保存於本機專用目錄；不將可能含真實人員資訊的證據上傳公開版本庫。
實體手機、完整五主題逐頁與完整 WCAG 尚未驗收，不以窄視窗測試冒充。
