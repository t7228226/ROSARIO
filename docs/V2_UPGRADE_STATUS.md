# ROSARIO v2 升級狀態

## 版本與發布

- 分支：`codex/v2-upgrade`
- 正式版本：`2026-08-02-003`
- 預覽環境預設為唯讀，仍可讀取目前 GAS 資料，但會阻擋所有寫入動作。
- 正式 GitHub Pages 已發布至 `main`。
- 正式 GAS 已更新為第 21 版，沿用既有網頁應用程式網址與部署作業 ID。
- Apps Script 專案已命名為「ROSARIO 站點資格管理系統」。

## 已完成

- 建立人力情境模型，統一缺勤、補訓、幹部支援及手動指派的計算入口。
- 使用最大匹配計算覆蓋，維持一人一站且重新計算全站缺口。
- 領班、組長、主任排除於基礎作業人力；站長正常計入。
- 訓練中人員不會自動安排，只能由使用者明確指定。
- 建立今日人力工作台與班別、日別摘要。
- 新增人員表單、重複工號檢查及 GAS `createPerson` 動作。
- 載入失敗不再用 0 筆資料覆蓋既有內容，提供持續錯誤狀態及重新讀取。
- 建立單元測試、GAS 動作契約檢查與 GitHub 品質檢查流程。
- 完成正式 GAS 版本、`P0033` 登入、資料重讀及 `createPerson` 無寫入契約驗證。
- 核心資料與三張權限表拆分載入，首頁不再等待權限管理資料。
- 停止由 bootstrap、登入及人員更新回應傳回密碼欄位。
- 新增人員支援 `validateOnly` 完整驗證，可在正式環境確認欄位與重複工號而不寫入資料。
- 寫入請求加入 `operationId`，相同操作逾時重送時不會重複執行。
- 前端逾時後會查詢 GAS 操作狀態，必要時才使用相同操作編號安全重送。
- 移除每次寫入前的重複版本查詢，版本仍由 GAS 在同一筆寫入中驗證。
- 所有 GAS 寫入動作共用文件鎖，降低手機與電腦同時修改造成的衝突。

## 獨立測試 GAS 設定

1. 複製正式試算表，建立專用測試副本。
2. 將本分支的 `gas-login-fallback-2026-07-01.js` 部署至測試副本。
3. 複製 `.env.preview.example` 為 `.env.preview.local`。
4. 將 `VITE_GAS_API_URL` 改成測試 GAS 網址。
5. 確認測試副本後才保留 `VITE_ENABLE_WRITES=true`。
6. 執行 `npm run dev:preview`，驗證新增後重整、重複工號與兩台裝置同時新增。
