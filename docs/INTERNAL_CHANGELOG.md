# 內部更新紀錄

此文件只供維護與測試追蹤，不會顯示在網站介面。

## 2026-08-02-003

- 新增可靠寫入操作編號 `operationId`。
- GAS 使用 Script Properties 保存 24 小時內的操作狀態與結果。
- 相同操作編號再次送達時，直接回傳既有結果，不重複寫入。
- 新增 `operationStatus` 查詢，供前端在逾時後確認寫入結果。
- 前端同內容的同時請求會共用同一個 Promise，阻擋快速重複點擊。
- 未確認結果會暫存在 `sessionStorage`，再次操作時沿用原操作編號。
- 移除每次寫入前的前端雙重版本查詢，改由 GAS 同請求驗證版本。
- 所有寫入動作統一使用文件鎖，新增人員不再自行建立巢狀鎖。
- 增加 GAS 防重複寫入自動測試與契約檢查。
- 支援舊 `v2` 名稱與新短版本名稱的正確新舊比較。
- 正式部署後停止舊版寫入，避免舊頁面繞過可靠寫入流程。
