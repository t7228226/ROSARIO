## 資源查閱與取捨

- 查詢已收錄 UI 資源目錄 `ui-reference-database.json`，選擇 `ui-ux-pro-max` 的排版、響應式及表格準則。
- 實際閱讀本機 `ux-guidelines.csv` 的標題層級、溢位、表格容器、行高、行長與字級相關內容。
- 實際查閱 [Carbon Data Table guidelines](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines) 的一致尺寸、工具列、漸進揭露與分頁。
- 採用資訊層級與漸進揭露方法，不匯入 Carbon 元件、CSS、素材或字型，避免新增框架或授權成本。
- 選單與詳細視窗沿用倉庫 `DialogShell`，保留既有按鈕與資料操作，不另安裝 UI 套件。
- 本次為作業介面精修，不增加裝飾圖片、背景特效或行銷版型；沿用已有品牌圖示。

## 實際前後差異

前測基準為本機私有證據目錄的 `website-audit-2026-10-23.md`；不是從建置成功推論視覺成功。

| 主要可見問題 | 修正 | 畫面確認 |
|---|---|---|
| 桌機常用導覽被展開的五主題推至視窗以下 | 導覽提前，品牌／帳號精簡，外觀設定收折 | 1440 × 900 首視窗可見完整九項主要導覽；最後一項約 y=723。 |
| 手機先看到大量設定，分析結論太低 | 結論與全站配置提前，四個工作頁籤，摘要站點與完整詳細視窗分層 | 390px 代表性預設分析內容由約 4379px 降至約 1612px；展開韌性明細後仍允許自然延伸，不宣稱所有狀態同高。 |
| 可拖曳功能鈕遮住內容及彈窗 | 邊緣吸附、閒置半隱藏、其他 dialog 開啟時避讓，選單焦點限制 | 實測拖曳到左側、外側／Escape 關閉與焦點還原；最窄 320px 無整頁溢位。 |

其他修正後確認：

- 姓名與標題維持置中；姓名標籤保留訓練字樣與黃色，不讓主題色取代風險語意。
- PNG 頁尾增加空間，實際檢視輸出後沒有與橫表重疊。
- 最後發現圓形按鈕受舊 CSS 影響，修正 specificity 後確認 58 × 58px、50% 圓角。
- 最後發現深色導覽選中字被舊 shell 色票覆蓋，修正變數作用域後量測淺字／深底並重新截圖確認。
